# Checklist SEO

قبل النشر، افحص هذه النقاط.

## 1. العناوين
- [ ] كل صفحة لها Title مختلف.
- [ ] Title يحتوي الكلمة المفتاحية الأساسية.
- [ ] Title غير مكرر.
- [ ] Title واضح وغير مضلل.

## 2. الوصف Meta Description
- [ ] كل صفحة لها وصف مختلف.
- [ ] الوصف بين 140 و160 حرفاً.
- [ ] الوصف يشجع النقر.
- [ ] لا يوجد وصف مكرر.

## 3. العناوين الداخلية
- [ ] كل صفحة لها H1 واحد.
- [ ] العناوين H2 وH3 منظمة.
- [ ] النص سهل القراءة.

## 4. الروابط
- [ ] لا توجد روابط مكسورة.
- [ ] الروابط الداخلية واضحة.
- [ ] canonical صحيح في كل صفحة.
- [ ] sitemap.xml محدث.
- [ ] robots.txt يحتوي على رابط sitemap.

## 5. الصور
- [ ] اللوغو واضح.
- [ ] الفافيكون يعمل.
- [ ] صورة OG موجودة.
- [ ] الصور مضغوطة.
- [ ] alt text موجود للصور المهمة.

## 6. التقنية
- [ ] HTTPS يعمل.
- [ ] الموقع يفتح على الموبايل.
- [ ] لا توجد أخطاء Console.
- [ ] سرعة الصفحة جيدة.
- [ ] 404 يعمل.
- [ ] .htaccess لا يسبب خطأ.

## 7. المحتوى
- [ ] الصفحة الرئيسية تشرح الموقع.
- [ ] صفحة About موجودة.
- [ ] صفحة Contact موجودة.
- [ ] Privacy Policy موجودة.
- [ ] Terms موجودة.
- [ ] لا يوجد محتوى منسوخ.
- [ ] كل أداة لها شرح.

## 8. AdSense
- [ ] المحتوى كافٍ قبل التقديم.
- [ ] لا توجد إعلانات مزعجة قبل القبول.
- [ ] سياسة الخصوصية تذكر الإعلانات والتحليلات.
- [ ] لا توجد صفحات مخفية.
- [ ] لا يوجد تحريض على النقر.

## 9. اللغات
- [ ] الإنجليزية مضبوطة.
- [ ] الترجمات مفهومة.
- [ ] hreflang مضاف عند تعدد اللغات.
- [ ] كل لغة لها sitemap خاص أو sitemap شامل.

## 10. بعد النشر
- [ ] إضافة الموقع إلى Google Search Console.
- [ ] إرسال sitemap.
- [ ] فحص التغطية Index Coverage.
- [ ] مراقبة أخطاء الزحف.
- [ ] إضافة Bing Webmaster Tools.
- [ ] متابعة الصفحات التي تحصل على ظهور.
