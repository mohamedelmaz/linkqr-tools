SMS Link Generator

Create an SMS link with a pre-filled message.

What is an SMS link?

An SMS link uses the sms: protocol to open the default messaging app with a pre-filled phone number and message.

How to use

Enter the phone number and message, click Generate, then copy the link. On mobile devices, clicking it opens the SMS app directly.
