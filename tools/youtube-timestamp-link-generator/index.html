YouTube Timestamp Link Generator

Create a YouTube link that starts at a specific second.

Supported URL formats

This tool supports the following YouTube URL formats:

  • youtube.com/watch?v=VIDEO_ID
  • youtu.be/VIDEO_ID
  • youtube.com/embed/VIDEO_ID
  • youtube.com/shorts/VIDEO_ID

Frequently asked questions

How do I find the timestamp of a moment?
Play the video, pause at the desired moment, and note the time shown in the player. Convert minutes to seconds (e.g., 2:30 = 150 seconds).

Does the timestamp work on mobile?
Yes. YouTube timestamp links work on both desktop and mobile devices.

Can I use this for YouTube Shorts?
Yes. Shorts URLs are supported, though timestamps are less commonly used for short videos.
