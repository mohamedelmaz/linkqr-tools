WhatsApp Link Generator

Create a WhatsApp link with a custom message and QR code.

What is a WhatsApp link?

A WhatsApp link is a URL that opens a WhatsApp chat with a specific phone number when clicked. If a message is included, WhatsApp opens with that message pre-filled.

WhatsApp link format

The basic format is https://wa.me/<countrycode><number>. If you add a message, it becomes https://wa.me/<countrycode><number>?text=<encoded-message>.

How to use this tool

Enter the country code, phone number, and an optional message. Click Generate. You will see the link and a QR code. You can copy the link or download the QR code image.

Where can you use the generated link?

You can share the link on websites, emails, social media, or print materials. When someone scans the QR code or clicks the link, WhatsApp opens on their device with the chat ready.

Frequently asked questions

Does this work without WhatsApp installed? On desktop, it opens WhatsApp Web. On mobile, it opens the WhatsApp app if installed, or the app store page otherwise.

Is the phone number stored anywhere? No. The tool runs in your browser and does not send any data to a server.

Can I use this for business? Yes, you can use the generated link for personal or business communication.
