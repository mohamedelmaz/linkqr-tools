Developers — LinkQR.js SDK

The first QR & link API with zero server costs — for you and for us. Unlimited, free, privacy-first.

💯 Drop the script in, call the methods, generate links and QR codes entirely in the browser. No backend, no limits, no tracking.

Quick Start

Add the SDK to your page and start generating links in seconds.

<script src="../assets/js/linkqr.sdk.js"></script>
<script>
    var url = LinkQR.whatsapp('1', '5551234567', 'Hello!');
    console.log(url);
    // → https://wa.me/15551234567?text=Hello%21

    LinkQR.qr(url, document.getElementById('my-qr'), 256);
</script>

API Reference

Method Parameters Returns
LinkQR.whatsapp(cc, phone, msg) Country code, phone number, message String — wa.me URL
LinkQR.telegram(user) Username or invite link String — t.me URL
LinkQR.sms(phone, msg) Phone number, message String — sms: URI
LinkQR.mailto(to, opts) Recipient, options (subject, cc, bcc, body) String — mailto: URL
LinkQR.wifi(ssid, pass, enc, hidden) SSID, password, encryption, hidden String — WIFI: QR payload
LinkQR.vcard(obj) Object with firstName, lastName, phone, email, org, url String — vCard 3.0 text
LinkQR.utm(url, params) Base URL, params (source, medium, campaign, term, content) String — URL with UTM
LinkQR.youtube(url, sec) YouTube URL, start seconds String — watch URL with t=
LinkQR.qr(text, el, size) Text, element, size Undefined — renders QR to element

FAQ

Is there a rate limit or daily cap?

No. The SDK runs entirely in the user's browser, so there are no server-side rate limits, API keys, or daily caps.

Do I need an API key?

No. LinkQR.js is a client-side utility library. Just include the script and call the methods — no signup, no key, no backend.
