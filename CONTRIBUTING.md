# Contributing to LinkQR Tools

Thank you for your interest in contributing! LinkQR Tools is a community-driven project built around privacy, simplicity, and browser-native tooling.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-tool`)
3. Commit your changes (`git commit -m "feat: add new tool"`)
4. Push to your branch (`git push origin feature/my-tool`)
5. Open a Pull Request

## Rules

- Keep the stack vanilla HTML/CSS/JS — no new frameworks or libraries.
- Never add backend services, tracking, or data collection.
- Use original wording; avoid copy-pasted content from other sites.
- Match the existing code style and folder structure.
