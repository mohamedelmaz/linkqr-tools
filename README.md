[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Free, privacy-first link & QR code tools that run **100% in the browser** — no signup, no watermarks, works offline.

## Features

### 14 Tools
**Links & QR**
- WhatsApp Link Generator
- WhatsApp QR Generator
- Telegram Link Generator
- YouTube Timestamp Link Generator
- Email Link Generator
- SMS Link Generator
- WiFi QR Generator
- vCard QR Generator
- UTM Builder
- Character Counter

**Calculators**
- Age Calculator
- Hijri-Gregorian Converter
- BMI Calculator
- Calorie Calculator

### Other Features
- **Dark Mode** — toggle with persistent preference
- **PWA / Offline** — installable, service worker cache
- **Printable WiFi Sign** — print-ready QR signage
- **Digital Signatures** — PNG signing support
- **SDK** — LinkQR.js for developers

## Live Demo

- Production: https://linkqr.tools
- GitHub Pages: https://USERNAME.github.io/linkqr-tools

## Tech Stack

- Pure HTML / CSS / JS
- QRCode.js (client-side)
- Service Worker (offline cache)
- No backend, no database

## Installation

```bash
git clone https://github.com/USERNAME/linkqr-tools.git
cd linkqr-tools
open index.html
```

## Deployment

### Hostinger / cPanel
Upload the folder contents to `public_html`.

### GitHub Pages
1. Settings → Pages
2. Source: Deploy from branch → `main` → `/ (root)`
3. Save and wait for deployment.
